## 1. Шкала стадий (Spec Kit)

| Стадия | Код | Смысл | Типичная команда |
|--------|-----|--------|------------------|
| Идея | `IDEA` | Есть потребность, нет `specs/NNN-…` | обсуждение |
| Спека | `SPEC` | Есть `spec.md` | `/speckit-specify` |
| План | `PLAN` | Есть `plan.md`, research/data-model | `/speckit-plan` |
| Задачи | `TASKS` | Есть `tasks.md` | `/speckit-tasks` |
| Код | `CODE` | Изменения в `.gs`, README | `/speckit-implement` |
| Проверка | `VERIFY` | Dry-run / live в Google Sheets | [quickstart](./001-sync-chain-04-02-05/quickstart.md) |
| Релиз | `SHIP` | Merge в `main`, деплой GAS, checkpoint | PR + заливка файлов |
| Отложено | `HOLD` | Блокер вне кода | — |

**Легенда «Кто»:** **В** — владелец (таблицы, GAS-деплой, бизнес-решения); **А** — ассистент (код, spec, tasks); **В+А** — вместе.
