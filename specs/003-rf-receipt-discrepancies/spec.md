# Feature Specification: Учёт расхождений при приёмке в РФ (3PL)

**Feature Branch**: `003-rf-receipt-discrepancies`

**Created**: 2026-05-21

**Status**: Implemented

**Input**: Импорт файла склада (CSV/XLSX), сверка с «Партии_в_рейсе» и «Декларации_строки», регистр расхождений, применение к себестоимости.

## User Scenarios & Testing

### User Story 1 — Импорт акта 3PL (P1)

**Given** рейс `TR-YYYY-NNNN` и файл склада, **When** оператор загружает файл через меню «📥 Приёмка», **Then** строки попадают на `Приемка_строки`, запись — в `Приемка_журнал`.

### User Story 2 — Сверка без записи в партии (P1)

**When** dry-run сверки по рейсу, **Then** лист `Расхождения_приемки` показывает SHORTAGE/SURPLUS/DEFECT/ASSORTMENT/CUSTOMS_VS_PHYSICAL без изменения «Партии_в_рейсе».

### User Story 3 — Применение подтверждённых qty (P2)

**Given** строки со статусом «подтверждено», **When** «Применить к партиям», **Then** создаётся бэкап партий, обновляются `Количество` и `Qty_для_аллокации` (годные шт), пересчёт себестоимости доступен отдельно.

## Functional Requirements

- FR-001: Ключ строки: `SHIPMENT_ID` + `Артикул ВБ` (+ `Номер спецификации` при наличии); fallback по `ШК`.
- FR-002: Типы расхождений: SHORTAGE, SURPLUS, DEFECT, ASSORTMENT, CUSTOMS_VS_PHYSICAL.
- FR-003: Источник факта — `Приемка_строки`; не писать в «Сводную» (01).
- FR-004: Таможенное qty — только по сматченным строкам `Декларации_строки` (`Артикул_ВБ` заполнен, статус не `pending`).
- FR-005: Допуск CUSTOMS_VS_PHYSICAL — Script Property `RECEIPT_CUSTOMS_QTY_TOLERANCE` (по умолчанию 0).
- FR-006: Событие `RECEIPT_ACCEPTED` в `События_рейса` — опционально после сверки.

## Data Model (книга 05)

| Лист | Назначение |
|------|------------|
| `Приемка_журнал` | Загрузки 3PL |
| `Приемка_строки` | Нормализованный факт |
| `Расхождения_приемки` | Результат сверки |
| `Справочник_маппинг_3PL` | Пресеты колонок |
| `Партии_в_рейсе` | + колонка `Qty_для_аллокации` |

## Out of Scope (MVP)

- Авто-заявки в реестр оплат
- Синхронизация прихода в МойСклад
- Изменение транзитных движений (02) по акту 3PL
