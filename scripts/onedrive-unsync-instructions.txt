Отключение синхронизации OneDrive для папки проекта
====================================================

Резервная копия кода: только локальная папка + GitHub (ежедневный push).
OneDrive для этой папки больше не нужен.

Вариант A — папка уже вне облака (рекомендуется)
------------------------------------------------
1. Скопируйте весь каталог «Автоматизация Gremlin» в путь БЕЗ OneDrive, например:
   C:\Dev\Gremlin
   или
   C:\Users\<имя>\Documents\Gremlin   (если «Документы» не синхронизируются с OneDrive)
2. Откройте новую папку в Cursor.
3. Проверьте: git remote -v  и  git push
4. Переустановите задачу планировщика из новой папки:
   powershell -ExecutionPolicy Bypass -File scripts\install-git-daily-task.ps1
5. Старую копию в OneDrive можно удалить после проверки push на GitHub.

Вариант B — оставить путь в OneDrive, но не синхронизировать
-------------------------------------------------------------
Если включена синхронизация «Документы» целиком:
  Параметры Windows → Учётные записи → Синхронизация параметров Windows
  или иконка OneDrive в трее → Параметры → Учётная запись → «Выбрать папки»
  — снимите галочку с «Документы», если проект только там.

Либо перенесите только эту папку (вариант A) — надёжнее.

Проверка: в проводнике у файлов проекта не должно быть значка «облако» / «синхронизация».
